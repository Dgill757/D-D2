# Pre-Demo Checklist - Lighthouse Presentation

Run through this 10 minutes before presenting.

---

## Hardware & Setup
- [ ] Laptop charged (or plugged in)
- [ ] External display / projector connected and mirrored
- [ ] Resolution set to 1920x1080 or higher
- [ ] Display scaling at 100% (not zoomed)
- [ ] Presenter view enabled (you see notes, audience sees slides)

## Software
- [ ] PowerPoint opened (not Google Slides - animations won't work)
- [ ] File: `Lighthouse_Demo.pptx` loaded
- [ ] Slideshow mode tested (F5 or Cmd+Shift+Return)
- [ ] All 10 slides render correctly
- [ ] Fonts display properly (Inter, JetBrains Mono fallback to system sans-serif)

## Visual Check (Quick Run-Through)
- [ ] Slide 1: Title readable, particles visible, date correct
- [ ] Slide 2: Timeline nodes visible, text not clipped
- [ ] Slide 3: Metrics cards showing Before/After correctly
- [ ] Slide 4: Problem bubbles around center icon look balanced
- [ ] Slide 5: Flow diagram nodes visible with detail panels below
- [ ] Slide 6: All 4 phases visible, right-side stats card readable
- [ ] Slide 7: Dashboard KPIs, charts, and table all render cleanly
- [ ] Slide 8: Voice AI capabilities + conversation preview visible
- [ ] Slide 9: All 6 industry cards visible in 2x3 grid
- [ ] Slide 10: Workflow diagram nodes + connections visible
- [ ] Progress dots visible at bottom of every slide

## Interactive Elements
- [ ] Home button (top right) navigates back to Slide 1
- [ ] Progress dots show current position
- [ ] All text is readable when projected (check from back of room)

## Presentation Environment
- [ ] Room lighting dimmed (dark slides look best in dim light)
- [ ] Close all other apps (no notifications popping up)
- [ ] Phone on silent / Do Not Disturb
- [ ] Water bottle nearby
- [ ] PRESENTER_NOTES.md open on second device or printed

## If Using Live Demo (Replit Dashboard)
- [ ] Browser tab with dashboard pre-loaded
- [ ] Dashboard data populated with sample records
- [ ] Internet connection confirmed and stable
- [ ] Have a fallback plan (Slide 7 IS the fallback)

## Last-Minute Reminders
- [ ] Take a breath before starting
- [ ] Slides 4-7 are the core story - spend the most time there
- [ ] The dashboard (Slide 7) is the money slide - don't rush it
- [ ] Keep it casual: "here's what we built" not "here's our pitch"
- [ ] If anything breaks: "That's live software for you"

---

**You're ready. Go show them what you built.**
